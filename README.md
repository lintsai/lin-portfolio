# Lin Tsai (蔡弘霖) - Personal Portfolio & Technical Advisory Website

> 軟體專案主管 · 解決方案架構師 · 企業 AI 應用專家  
> 10~11 年軟體架構實務 × 5 年技術團隊管理 (9~12 人敏捷團隊)

---

## 🌟 核心特色 (Key Features)

- **雙核心模組架構**：
  - 💼 **個人經歷與實績專頁 (`/`)**：包含 30 秒三大領域看板 (3 Pillars)、34+ 完整專案庫（即時搜尋、分類篩選、彈窗詳解）、職涯時間軸、技能矩陣與學歷證照。
  - 🚀 **技術諮詢與專案協作頁 (`/services`)**：展示 4 大務實交付方案、3 大實戰架構思維剖析與透明的 3 階合作計價模式。
  - 🔒 **內部定價指南 (`/pricing-internal`)**：個人私密參考手冊，內建即時互動報價試算器與一鍵複製回信範本。
- **廣告級動態體驗 (Scroll Reveal)**：GPU 硬體加速滾動進場與柔和毛玻璃質感。
- **現代技術棧**：Nuxt 4、Vue 3、TypeScript、Tailwind CSS、Nitro Server。

---

## 🚀 快速啟動 (Quick Start)

```bash
# 1. 安裝依賴
npm install

# 2. 啟動本地開發伺服器
npm run dev

# 3. 生產打包構建
npm run build

# 4. 本地預覽生產打包
npm run preview
```
